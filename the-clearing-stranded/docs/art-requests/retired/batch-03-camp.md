the style reference; **[also attach: file]** is a second picture to attach. Save each picture with the exact file
name given, zip them, and send the zip back. High resolution is fine; I'll compress everything.

boulders, trees, trails and fire ring must not move at all, because the game's walkable ground is traced from
`01-camp.png`. If an edit shifts things, try again, or tell me.

(or flat light gray #D9D9D9 if your tool can't do transparency), seen from the same angle as the places. Draw them
large; the game shrinks them and sets them down in the camp's open grass, by the river, and so on.
