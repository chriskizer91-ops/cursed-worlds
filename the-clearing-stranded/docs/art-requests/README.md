## How to use this

1. Open a batch file and go down it in order.
2. Paste each prompt (the quoted block under each heading) into your image tool.
3. Attach **`01-camp.png`** (the camp painting you already made) as the style reference for every one of them.
4. Save each picture with the exact file name the prompt gives, like `02-cedar-stand.png`.
5. Zip them and send the zip back. High resolution is fine; I'll compress everything for the game.

It helps to make each picture two to four times and keep the best one.

## Things that hold for every picture

- **Always daytime, late spring**, with the sun high in the upper left. The game makes the dusk, the night, the
  summer, the fall, the winter and the snow itself.
- **Nothing made by people**: no roads, fences, buildings, ruins or trash. If one sneaks in, try again.
- **No people, animals or text.** The game puts the survivor and the animals in.
- **No fruit on the fruit plants** (berries, mulberries, plums, grapes, persimmons, prickly pear). The game adds
  the ripe fruit at the right time of year.

## If a painting moves things

Every place prompt lists where things go, as *percent across* from the left and *percent down* from the top. Close
is good enough. The camp painting moved its trails and boulders a little, and that was fine: I traced the game to
the painting instead. If you like a picture, keep it.

## Retired

`retired/` keeps the prompts that are now made in code (the survivor sheets, the camp's things, the animals, the
season repaints and the icons), in case any of them is ever wanted again.
